# KNOCK — *The Door I Didn't Know I Was Leaving*

[![GitHub](https://img.shields.io/badge/GitHub-smhavci%2FKNOCK-181717?style=flat&logo=github)](https://github.com/smhavci/KNOCK)

> *"Knock, knock, knockin' on heaven's door..."*  
> — Bob Dylan, Pat Garrett & Billy the Kid (1973)

**KNOCK** is an AI-powered creative web application that transforms a personal childhood memory into two things: a handcrafted poem in the tradition of Bob Dylan's sparest writing, and a 1970s film-photograph image that captures the emotional residue of that memory.

The result is your **door** — the one you didn't know you were leaving.

**Live Demo:** [https://knock-production-ccf7.up.railway.app](https://knock-production-ccf7.up.railway.app)

---

## What It Does

1. You type a childhood memory into a text field
2. **Claude** (Anthropic's LLM) reads it and writes a 10–16 line poem in Dylan's 1973 register — sparse, concrete, aching
3. A second Claude model distills the poem into a single visual scene
4. **DALL-E 3** renders that scene as a 35mm film photograph from 1973 — heavy grain, faded amber, Sam Peckinpah stillness
5. Your door joins a **collective gallery** — a wall of unnamed moments where strangers' lost childhoods hang alongside yours

---

## Artistic Concept

The song "Knockin' on Heaven's Door" was written for a dying sheriff in a Peckinpah film. He was laying down his badge — not because he was dying, but because he couldn't use it anymore. Dylan made that small, specific gesture universal.

KNOCK uses that gesture as a lens for childhood. Not death, but the laying down. The moment something — a season, a self, a version of home — quietly stopped belonging to you. Most of the time, you didn't feel the door swing shut. You only notice it later, from the other side.

The two AI models aren't decoration. They are collaborators in excavation: the LLM finds the emotional truth in language, the diffusion model finds it in light and texture. Together they render what memory actually feels like: not the event, but the weight it left.

## Tech Stack

| Layer | Technology | Why |
|-------|-----------|-----|
| **Backend** | Python + FastAPI | Fast setup, clean async API, streaming support |
| **LLM (Poem)** | Anthropic Claude (`claude-sonnet-4-6`) | Best creative writing quality; prompt-cached system prompt |
| **LLM (Visual)** | Anthropic Claude (`claude-haiku-4-5`) | Fast, cheap visual core extraction |
| **Image Gen** | OpenAI DALL-E 3 | Faithful to complex aesthetic prompts, excellent API |
| **TTS** | ElevenLabs API + OpenAI TTS fallback | Voice reading of the poem |
| **Frontend** | HTML + CSS + Vanilla JS | Zero framework overhead, full aesthetic control |
| **Database** | SQLite | Lightweight persistence for the collective gallery |
| **Auth** | JWT + bcrypt | Simple user accounts for gallery attribution |

### AI Techniques Used

1. **Large Language Model (LLM)** — Claude generates poetry from free-text memories using a carefully crafted system prompt that establishes tone, voice, craft rules, and prohibitions. A second, faster model extracts the visual core.

2. **Text-to-Image Diffusion Model** — DALL-E 3 renders photographic images from prose descriptions. The image prompt encodes specific aesthetic constraints: 35mm film grain, 1973 color palette, available light, Sam Peckinpah cinematography references.

Both models interact: the poem generated by the LLM informs the visual extraction, which informs the image prompt. Memory → Language → Image is a chain, not a parallel operation.

## Setup & Installation

### Requirements

- Python 3.11+
- API Keys:
  - **Anthropic** (Claude): [console.anthropic.com](https://console.anthropic.com)
  - **OpenAI** (DALL-E 3 + TTS): [platform.openai.com](https://platform.openai.com)
  - **ElevenLabs** (optional, TTS): [elevenlabs.io](https://elevenlabs.io)

---

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/knock.git
cd knock
```

### 2. Set Up the Backend

```bash
cd backend

# Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Configure API Keys

Create `backend/.env`:

```env
ANTHROPIC_API_KEY=your_anthropic_key_here
OPENAI_API_KEY=your_openai_key_here
ELEVENLABS_API_KEY=your_elevenlabs_key_here   # optional
```

Create `frontend/config.js`:

```js
const API_BASE = "http://127.0.0.1:8000";
```

### 4. Run the Backend

```bash
# From inside /backend with venv activated
uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.  
Health check: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)

### 5. Open the Frontend

Open `frontend/index.html` directly in your browser, or serve it with any static file server:

```bash
# From the project root
python3 -m http.server 3000 --directory frontend
# Then visit http://localhost:3000
```

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| `GET` | `/health` | — | Health check |

| `POST` | `/speak` | — | Text-to-speech for a poem |
| `GET` | `/gallery` | — | Retrieve all saved doors |

### `/create-door` — Server-Sent Events Stream

**Request:**
```json
{ "memory": "We used to have water fights in the garden with a hose every summer..." }
```

**SSE Event Types:**
```
data: {"type": "poem", "text": "...chunk..."}    # streamed poem text
data: {"type": "image_loading"}                   # DALL-E started
data: {"type": "image", "url": "..."}             # final image URL
data: {"type": "done"}                            # complete
data: {"type": "error", "detail": "..."}          # on failure
```

## Key Design Decisions

**Why streaming?** The poem appears word by word as Claude writes it — like watching someone think. This transforms a loading screen into part of the experience.

**Why two Claude models?** The poem model (Sonnet) needs maximum creative quality. The visual extraction (Haiku) is a simpler classification task — fast and cheap. Using the right model for each task reduces latency and cost.

**Why save images locally?** DALL-E URLs expire after ~1 hour. The gallery needs permanent URLs, so images are downloaded and served from the FastAPI static files directory.

**Why no React/Vue?** The aesthetic requires pixel-level CSS control. A framework's component model would fight the 1970s film grain overlay, the typewriter timing, the ambient audio fade. Vanilla JS gives full control with zero abstraction cost.
